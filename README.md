# Snoopy Storyboard Game

A super cute interactive story game featuring Snoopy and Woodstock! 
In this game, you get to decide how Snoopy and Woodstock spend the perfect autumn afternoon, whether it's enjoying the cool weather outside, or enjoying some cozy fall activities inside!

## How to Play
You can play the game right in your web browser! No downloads needed:
**[Play the Snoopy Game Here](https://riya20-0802.github.io/my-renpy-game/)**

## What it Does
- Features custom storyboards, dialogue, and choices with Snoopy.
- Works directly on desktop and mobile browsers.

## Built With Ren'Py
- Made with [Ren'Py Engine](https://www.renpy.org/)
- Hosted on GitHub Pages

I hope you enjoy playing it just as much as I enjoyed creating it!!
